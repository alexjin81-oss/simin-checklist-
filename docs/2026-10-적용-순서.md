# 2026-10 개정 적용 순서

서버(Apps Script)를 먼저 바꾸고, 그다음 화면(GitHub → Vercel)을 올린다.
새 서버는 예전 화면과도 동작하므로 이 순서면 중간에 끊기지 않는다.
(단, 관리 화면의 대표·생산총괄 메뉴는 새 화면이 올라가야 쓸 수 있다.)

## 1. 스크립트 속성 3개 넣기 — 값은 대표가 직접 입력
"시민제과_생산 관리시스템" 시트 → 확장 프로그램 → Apps Script → 왼쪽 톱니(프로젝트 설정) → 스크립트 속성

| 속성 | 값 |
|---|---|
| `NOTION_TOKEN` | 노션에서 새로 발급한 통합 토큰 (기존 토큰은 폐기) |
| `CEO_PIN` | 대표 메뉴 비밀번호 |
| `SUPERVISOR_PIN` | 생산총괄 메뉴 비밀번호 |

## 2. Apps Script 코드 교체
- "시민제과_생산 관리시스템" 시트의 `Code.gs` ← `apps-script/manage-api.gs`
- "시민제과_생산기록" 시트의 `Code.gs` ← `apps-script/production-api.gs`
- 각각 저장 후 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** (주소가 바뀌지 않는다)
- 관리시스템 편집기에서 `setupCheck` 실행 → 전부 true 인지 확인

## 3. 화면 올리기
`simin-clean/` 아래 변경 파일을 GitHub main 에 반영하면 Vercel 이 자동 배포한다.

## 4. 한 번만 실행
관리시스템 편집기에서 `buildCleanInventoryTabs` 실행 →
`정리_재고_2F/3F/4F` 탭 생성 (기존 `재고_*` 탭은 그대로 둔다).

## 5. 직원 안내 (재고 입력 방식이 바뀜)
- 칸이 비어 있다. 세어서 숫자를 넣거나, 변동이 없으면 "같음"을 누른다.
- 입력하지 않은 품목은 저장되지 않는다.
- 어제와 크게 다른 숫자는 "맞아요"를 눌러야 저장된다.
- 생산기록: 어제분을 늦게 올릴 때는 기록 날짜를 "어제"로 고른다.
